// Variable global lưu thông tin cấu hình và dữ liệu let priceMap = {}; // Lưu thông tin Giá (F), Giới hạn số lượng (E), Tiền tối đa (G) từ sheet Thong_tin_chung let allData = []; const CACHE_KEY = "DANG_KY_NUOC_DATA_CACHE"; // ID Sheet Google của bạn const SHEET_ID = "YOUR_SPREADSHEET_ID_HERE"; const GID_SO_LUONG = "0"; // Thay bằng GID thực tế của sheet So_luong_dat const GID_THONG_TIN = "12345678"; // Thay bằng GID thực tế của sheet Thong_tin_chung /** * 1. Đọc dữ liệu từ sheet Thong_tin_chung * Cột B (cols[1]): Mã (A1, A2, A3, A4) * Cột E (cols[4]): Số lượng giới hạn * Cột F (cols[5]): Đơn giá * Cột G (cols[6]): Tổng tiền tối đa */ function parsePriceData(csvText) { let lines = csvText.split(/\r?\n/); priceMap = { 'A1': { price: 0, limitQty: 0, maxAmount: 0 }, 'A2': { price: 0, limitQty: 0, maxAmount: 0 }, 'A3': { price: 0, limitQty: 0, maxAmount: 0 }, 'A4': { price: 0, limitQty: 0, maxAmount: 0 } }; for (let i = 1; i < lines.length; i++) { if (!lines[i].trim()) continue; let cols = parseCSVLine(lines[i]); if (cols.length >= 2) { let key = cols[1] ? cols[1].trim().toUpperCase() : ""; // Mã A1, A2... if (key && priceMap.hasOwnProperty(key)) { // Cột E (cols[4]): Số lượng giới hạn let limitQty = cols[4] ? parseFloat(cols[4].replace(/[^0-9.-]+/g, "")) : 0; // Cột F (cols[5]): Giá tiền let price = cols[5] ? parseFloat(cols[5].replace(/[^0-9.-]+/g, "")) : 0; // Cột G (cols[6]): Tổng tiền tối đa let maxAmount = cols[6] ? parseFloat(cols[6].replace(/[^0-9.-]+/g, "")) : 0; priceMap[key] = { price: isNaN(price) ? 0 : price, limitQty: isNaN(limitQty) ? 0 : limitQty, maxAmount: isNaN(maxAmount) ? 0 : maxAmount }; } } } } /** * 2. Hàm hiển thị dữ liệu bảng và chèn 2 hàng tổng vào cuối */ function renderTable(dataArray) { const tbody = document.getElementById('table-body'); const tfoot = document.getElementById('table-foot') || createTfoot(); tbody.innerHTML = ''; tfoot.innerHTML = ''; if (!dataArray || dataArray.length === 0) { tbody.innerHTML = 'Không tìm thấy dữ liệu phù hợp.'; return; } // Các biến tích lũy cho Hàng tổng 1 (Tổng đăng ký) let sumQty1 = 0, sumQty2 = 0, sumQty3 = 0, sumQty4 = 0; let sumAmt1 = 0, sumAmt2 = 0, sumAmt3 = 0, sumAmt4 = 0; let totalAllAmount = 0; // Lặp qua từng dòng dữ liệu để vẽ bảng và tính tổng dataArray.forEach((row, index) => { // Tính tiền từng loại dựa trên giá từ priceMap let amt1 = (row.qty1 || 0) * (priceMap['A1'] ? priceMap['A1'].price : 0); let amt2 = (row.qty2 || 0) * (priceMap['A2'] ? priceMap['A2'].price : 0); let amt3 = (row.qty3 || 0) * (priceMap['A3'] ? priceMap['A3'].price : 0); let amt4 = (row.qty4 || 0) * (priceMap['A4'] ? priceMap['A4'].price : 0); let rowTotal = amt1 + amt2 + amt3 + amt4; // Cộng dồn Hàng 1 sumQty1 += (row.qty1 || 0); sumQty2 += (row.qty2 || 0); sumQty3 += (row.qty3 || 0); sumQty4 += (row.qty4 || 0); sumAmt1 += amt1; sumAmt2 += amt2; sumAmt3 += amt3; sumAmt4 += amt4; totalAllAmount += rowTotal; // Vẽ hàng dữ liệu thông thường let tr = document.createElement('tr'); tr.innerHTML = ` ${index + 1} ${escapeHtml(row.unit)} ${escapeHtml(row.month)} ${formatNumber(row.qty1)} ${formatNumber(row.qty2)} ${formatNumber(row.qty3)} ${formatNumber(row.qty4)} ${formatCurrency(amt1)} ${formatCurrency(amt2)} ${formatCurrency(amt3)} ${formatCurrency(amt4)} ${formatCurrency(rowTotal)} `; tbody.appendChild(tr); }); // Lấy thông tin Giới hạn (Cột E) và Tiền tối đa (Cột G) cho Hàng 2 let limitA1 = priceMap['A1'] ? priceMap['A1'].limitQty : 0; let limitA2 = priceMap['A2'] ? priceMap['A2'].limitQty : 0; let limitA3 = priceMap['A3'] ? priceMap['A3'].limitQty : 0; let limitA4 = priceMap['A4'] ? priceMap['A4'].limitQty : 0; let maxAmtA1 = priceMap['A1'] ? priceMap['A1'].maxAmount : 0; let maxAmtA2 = priceMap['A2'] ? priceMap['A2'].maxAmount : 0; let maxAmtA3 = priceMap['A3'] ? priceMap['A3'].maxAmount : 0; let maxAmtA4 = priceMap['A4'] ? priceMap['A4'].maxAmount : 0; // Tổng tiền tối đa ở ô cuối cùng (Cột Kế toán/Tổng tiền) let grandTotalMaxAmount = maxAmtA1 + maxAmtA2 + maxAmtA3 + maxAmtA4; // --- HÀNG 1: TỔNG SỐ LƯỢNG VÀ TỔNG TIỀN ĐĂNG KÝ --- let trTotal = document.createElement('tr'); trTotal.className = 'row-summary-total'; trTotal.style.fontWeight = 'bold'; trTotal.style.backgroundColor = '#e8f5e9'; // Màu nền xanh nhẹ nổi bật trTotal.innerHTML = ` TỔNG CỘNG ĐĂNG KÝ ${formatNumber(sumQty1)} ${formatNumber(sumQty2)} ${formatNumber(sumQty3)} ${formatNumber(sumQty4)} ${formatCurrency(sumAmt1)} ${formatCurrency(sumAmt2)} ${formatCurrency(sumAmt3)} ${formatCurrency(sumAmt4)} ${formatCurrency(totalAllAmount)} `; // --- HÀNG 2: SỐ LƯỢNG GIỚI HẠN & TỔNG TIỀN TỐI ĐA --- let trLimit = document.createElement('tr'); trLimit.className = 'row-summary-limit'; trLimit.style.fontWeight = 'bold'; trLimit.style.backgroundColor = '#fff3e0'; // Màu nền cam nhẹ phân biệt trLimit.innerHTML = ` SỐ LƯỢNG GIỚI HẠN / TIỀN TỐI ĐA ${formatNumber(limitA1)} ${formatNumber(limitA2)} ${formatNumber(limitA3)} ${formatNumber(limitA4)} ${formatCurrency(maxAmtA1)} ${formatCurrency(maxAmtA2)} ${formatCurrency(maxAmtA3)} ${formatCurrency(maxAmtA4)} ${formatCurrency(grandTotalMaxAmount)} `; tfoot.appendChild(trTotal); tfoot.appendChild(trLimit); } // Hàm hỗ trợ tạo thẻ nếu trong HTML chưa có function createTfoot() { const table = document.querySelector('table'); let tfoot = table.querySelector('tfoot'); if (!tfoot) { tfoot = document.createElement('tfoot'); tfoot.id = 'table-foot'; table.appendChild(tfoot); } return tfoot; } // Các hàm tiện ích định dạng dữ liệu function formatNumber(num) { if (!num || isNaN(num)) return '0'; return new Intl.NumberFormat('vi-VN').format(num); } function formatCurrency(amt) { if (!amt || isNaN(amt)) return '0 đ'; return new Intl.NumberFormat('vi-VN').format(amt) + ' đ'; } function escapeHtml(str) { if (!str) return ''; return str.replace(/&/g, "&").replace(//g, ">"); } // Hàm phân tách CSV cơ bản function parseCSVLine(text) { let result = []; let cell = ''; let inQuotes = false; for (let i = 0; i < text.length; i++) { let c = text[i]; if (c === '"') { inQuotes = !inQuotes; } else if (c === ',' && !inQuotes) { result.push(cell.trim()); cell = ''; } else { cell += c; } } result.push(cell.trim()); return result; }
